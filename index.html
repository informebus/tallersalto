📚 Manual de Boletera

1. Arranque de Turno

  • Login: Presioná la tecla H. Ingresá tu número de funcionario y confirmá con OK.
  • PIN: Ingresá 1234.
  • Habilitar: Presioná la letra N y luego OK ("datos descargados").
  • Inicio: Presioná la letra L (emite ticket inicio).
  • Línea: Presioná la letra C + OK. Nro Línea + OK + Nro Conexión + OK.
  • Pantalla Venta: Letra S + Escape.

2. Ventas

  • Común: Presionar OK.
  • Combinación: Letra M + OK.
  • Multiventa: Letra G + Cantidad + OK + P (Vender).
  • Anular (Máx 3 min): Letra F + Nro Boleto + OK.

3. Cierres y Controles

  • Pasada/Llegada: Letra N.
  • Cambiar Conexión: Letra C.
  • Inspección: Letra T.
  • Arqueo: Letra L.
  • Cerrar Viaje: Letra S.
  • LIQUIDAR (Fin de turno): Letra Q.
